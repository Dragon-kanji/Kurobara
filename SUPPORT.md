# Support

Kurobara currently provides community support through
[GitHub issues](https://github.com/Dragon-kanji/Kurobara/issues). There is no
commercial support, SLA, guaranteed response, or supported release branch.

## Before opening an issue

Include:

- your goal;
- exact Git commit or release;
- operating system, architecture, Node, npm, and Docker versions;
- minimal reproduction steps using synthetic data;
- expected and observed behavior;
- exact redacted error;
- checks already run;
- what you could not verify.

Remove provider keys, API keys, tokens, authorization headers, personal data,
provider payloads, signed URLs, private paths, dumps, and confidential logs.

Use [GitHub private vulnerability reporting](https://github.com/Dragon-kanji/Kurobara/security/advisories/new)
for anything security-sensitive. Do not open a public issue first.

Community answers do not create a compatibility, maintenance, or release
commitment. Operators remain responsible for backups, credentials, provider
terms, costs, retention, and recovery.
